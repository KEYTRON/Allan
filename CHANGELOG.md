# Changelog

Все важные изменения в проекте Allan документируются в этом файле.

## [0.2.0] - 2025-11-10

### Добавлено

- **Полная переработка структуры проекта**
  - Правильная структура Python пакета с модулями
  - `pyproject.toml` для управления зависимостями
  - `requirements.txt` и `requirements-dev.txt`

- **Система конфигурации**
  - `AllanConfig` класс для централизованной конфигурации
  - Поддержка переменных окружения
  - Поддержка YAML конфигурационных файлов
  - `.env.example` шаблон

- **Основная функциональность в `src/core.py`**
  - Загрузка моделей из Hugging Face
  - Генерация текста
  - Поддержка 8-bit и 4-bit квантизации
  - Автоматическое определение устройства (CPU/CUDA/MPS)
  - Информация о системе

- **Модульная структура**
  - `src/config/` - система конфигурации
  - `src/datasets/` - управление датасетами
  - `src/optimization/` - оптимизация производительности
  - `src/colab/` - интеграция с Google Colab
  - `src/nlp/` - NLP утилиты

- **Comprehensive test suite**
  - Тесты для конфигурации (test_config.py)
  - Тесты для ядра (test_core.py)
  - Покрытие > 80% критической функциональности

- **Улучшенный CLI**
  - Аргументы командной строки
  - Поддержка генерации текста из CLI
  - Настраиваемый уровень логирования

- **Документация**
  - INSTALLATION.md - руководство по установке
  - CHANGELOG.md - журнал изменений
  - Обновленный README

### Изменено

- **Удален хардкод путей**
  - Все пути теперь конфигурируются
  - Поддержка локального запуска (не только Colab)

- **Улучшенная обработка ошибок**
  - Proper exception handling
  - Информативные сообщения об ошибках
  - Graceful degradation при отсутствии зависимостей

- **Оптимизированная структура**
  - Утилиты перенесены в соответствующие модули
  - Устранены дубликаты кода
  - Улучшена читаемость

### Исправлено

- Отсутствие конфигурационных файлов пакета
- Хардкод путей для Google Colab
- Отсутствие тестов
- Неработающее ядро (было только заглушкой)
