# Дорожная карта Allan

Стадия: 0.4.0

Этапы идут по порядку: `[x]` — сделано, `[ ]` — в планах. Текущий этап — первый незавершённый.

## Ядро агента
- [x] Цикл ReAct с вызовом инструментов
- [x] Инструменты: shell с проверкой опасных команд, чтение и запись файлов, веб-поиск, SSH
- [x] PTY-режим: интерактивные команды и `sudo` внутри агента
- [x] Сжатие scratchpad в длинных сессиях

## Терминальный интерфейс
- [x] TUI на Bubbletea: slash-команды с автодополнением, история ввода
- [x] Вызовы инструментов отдельными блоками со статусом
- [x] Итог сессии при выходе
- [x] Новый интерфейс: единый фон, карточка приветствия, поле ввода в рамке, спиннер, Markdown в ответах, свёрнутый вывод инструментов, прокрутка колесом мыши, `allan --help` на русском
- [x] Навигация клавишами: списки выбора модели и провайдера (↑↓, поиск, Enter), Enter выполняет подсказку, Esc останавливает агента, Ctrl+C дважды для выхода

## Память и навыки
- [x] Память на SQLite: сессии, диалоги, факты с полнотекстовым поиском, `--resume`
- [x] Семантическая память в ChromaDB
- [x] Skill Engine: удачные решения сохраняются навыками и переиспользуются

## Модели
- [x] Бэкенды Anthropic, OpenAI, Ollama, llama.cpp и LM Studio
- [x] Автоматический выбор доступного локального бэкенда
- [x] Ключи провайдеров прямо из TUI (`/api`) и выбор модели из каталога в `/model`
- [x] Grok (xAI) как провайдер
- [x] Облачные провайдеры: OpenRouter, OpenCode Zen, Ollama Cloud (по API-ключу, отдельно от локального Ollama), Hugging Face Inference Providers, Featherless.ai, Z.ai
- [x] Ключи в системном keyring (запасной вариант — файл 0600), свои эндпоинты, `allan key` со скрытым вводом
- [x] GigaChat (Сбер): OAuth по ключу авторизации, встроенный сертификат Минцифры, вызов функций
- [x] Подпись модели под ответом, `/compact` — сжатие истории в сводку
- [x] Языки интерфейса: ru (исходный), en, de — `/lang`, `--lang`, `tui.lang` в конфиге
- [x] `allan serve`: фоновый HTTP/SSE-воркер для телефона и сайта, авторизация по токену, сессии по клиентам
- [x] `allan connect` и `/connect`: привязка машины к KEYTRON Prime (одноразовый код со страницы, токен в keyring)
- [x] `--resume [id]` действительно продолжает диалог: история грузится и показывается, можно указать конкретную сессию
- [x] Повтор вместо перенабора: после `/model` прерванный запрос повторяется на новой модели (есть и `/retry`)
- [x] Skill Engine больше не пишет навыки на приветствия и ходы в одну тулзу (кулдаун, проверка дублей, `skill_enabled`)
- [ ] Поддержка MCP: подключение MCP-серверов (stdio и HTTP) как инструментов агента
- [ ] Проверка агента на бесплатных моделях (OpenRouter free, Ollama Cloud Free): вызовы инструментов, длинные сессии
- [x] Несколько ПК на одном аккаунте: стабильный `machine_id` (`allan id`, видно в `--help`), имя и адрес воркера при `allan connect`, выбор ПК в приложении; изоляция воркеров между пользователями
- [x] Запасное хранилище секретов: если связка ключей отказывает (macOS по SSH), токен пишется в `~/.allan/secrets.json` (0600)
- [x] Пакеты WARP `allan` 0.4.0 для linux-x86_64, linux-aarch64, android-aarch64 (Termux) и macos-aarch64; пакет `go` 1.27.1 для Termux
- [ ] Свои API-ключи у пользователей воркера, чтобы дать человеку доступ к его моделям
