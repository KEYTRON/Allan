# Дорожная карта Allan

Стадия: 0.3.1

Этапы идут по порядку: `[x]` — сделано, `[ ]` — в планах. Текущий этап — первый незавершённый.

## Ядро агента
- [x] Цикл ReAct с вызовом инструментов
- [x] Инструменты: shell с проверкой опасных команд, чтение и запись файлов, веб-поиск, SSH
- [x] PTY-режим: интерактивные команды и `sudo` внутри агента
- [x] Сжатие scratchpad в длинных сессиях

## Терминальный интерфейс
- [x] TUI на Bubbletea: slash-команды с автодополнением, история ввода
- [x] Вызовы инструментов отдельными блоками со статусом
- [x] Итог сессии при выходе
- [x] Новый интерфейс: единый фон, карточка приветствия, поле ввода в рамке, спиннер, Markdown в ответах, свёрнутый вывод инструментов, прокрутка колесом мыши, `allan --help` на русском

## Память и навыки
- [x] Память на SQLite: сессии, диалоги, факты с полнотекстовым поиском, `--resume`
- [x] Семантическая память в ChromaDB
- [x] Skill Engine: удачные решения сохраняются навыками и переиспользуются
